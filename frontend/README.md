# Ivory & Sage Dental Studio — Frontend

The Next.js frontend for Ivory & Sage Dental Studio, created and developed by Jagrit Sharma.

It includes the responsive clinic landing page, GSAP scroll motion, treatment comparisons, patient stories, FAQs,
doctor profiles, and appointment booking flows.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) for optimized typography.
